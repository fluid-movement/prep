# prep

prep is a workflow engine and memory for coding agents, with a human supervising. It keeps issues, their lifecycle records and a knowledge base of decisions and findings in the repository under `.prep/`, versioned with the code.

- **[Getting started](getting-started.md)**: install prep and run your first issue.
- **[Workflow](workflow.md)**: define, enrich, implement and complete, with a separate check.
- **[Commands](commands.md)**: every command, generated from `prep help`.
- **[Harness integrations](harness-integrations.md)**: Claude Code and Codex.
- **[Cloud sessions](cloud-sessions.md)**: hand issues to Claude Code cloud sessions and merge the results.
- **[Knowledge base](knowledge-base.md)**: decisions and findings that outlive the issue.
- **[TUI](tui.md)**: a terminal UI next to your agent.

Source and releases: [github.com/fluid-movement/prep](https://github.com/fluid-movement/prep).
