Query-first layout like lazygit or k9s. Saved views from config.yaml are tabs (Attention, Actionable, In progress, To enrich, To define, All). A filter bar accepts the same flags as prep list. Any result can be shown flat or with its ancestors. The detail pane renders the issue's records, a diff of requirement vs newest baseline for stale issues, the check output with fixes, and a settings screen for the project config.
