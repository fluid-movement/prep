Editing works inline in the TUI and by opening the file in $EDITOR with validation on close. Transitions in the TUI: create, reparent and edit the requirement for all kinds; complete only manual, research and decision issues (code issues are completed by an agent with commit evidence); drop with a reason in any state; acknowledge a stale change. Copying an issue ID to hand to the agent is the minimal flow for starting work.
