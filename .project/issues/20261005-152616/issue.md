title: 'TUI: human client next to the harness'
kind: code
---

A terminal UI (Bubble Tea, Bubbles, Lip Gloss, Glamour) that runs next to the agent harness and updates live by watching .project. It is the human client to the data: reading, editing and a subset of transitions. It uses the same query engine as the CLI so both agree on derived states.
