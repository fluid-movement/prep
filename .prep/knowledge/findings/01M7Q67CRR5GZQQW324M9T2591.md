## Blank request event (from source, not observed)

Kind is `request` when the payload has token usage, else `gap` (activity.KindGap), with Op set to the model name. A gap, or a request whose model is empty, would show a blank value. Unknown: which of these the earlier blank event was.

## "hook skipped" (from source)
- prompt/skipped: hookSendPrompt returns false when the prompt reminder text equals what this session last received (state file `.sent`), so the text is not re-sent. Recorded as `hookRecord(..., "skipped")`.
- finish/skipped: internal/cli/hook_finish.go:253 records "skipped" with target "N files" when the Stop question is not asked for the code changes.
Valid verbs (internal/activity/activity.go hookVerbs): prompt {sent, skipped, error}; finish {asked, skipped, error}; before-tool {denied read, denied write, context, error}; session-start {primed, error}.
