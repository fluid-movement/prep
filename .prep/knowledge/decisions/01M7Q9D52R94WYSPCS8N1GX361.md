---
type: decision
title: Failed requests stay valid without usage; zero-usage requests are rejected
description: Event.Validate rejects an all-zero request unless its status is failed.
date: "2026-11-18"
issue: 01M7Q923PB7QG1D1XZ0075V63M
---

The implementer found that rejecting every all-zero request breaks the existing attribution test, which records a failed request with no usage. A failed model request legitimately has no token counts and still matters for coverage, so it stays valid. A request that claims success (or has no status) but has no usage is the blank-row case from the cloud findings and is rejected. Alternative considered: dropping status as evidence entirely, which would hide failed requests from the activity stream.
