The user delegated the open choice. A second version field would duplicate the schema number and could disagree with it; the schema changes exactly when stored records change shape. A repository that needs a newer binary for a feature without a schema change is a release-notes matter. The cloud case is handled by clear messages and the pinned script, not a new field.
