Each prompt repeated the same reminder and guides, injecting the same context over a long session. Per-session last-sent text lives in .prep/local/hooks next to the turn snapshot, keyed by harness and session. A missing or unreadable record means send. Without a session id nothing can be keyed, so text is always sent. The turn snapshot is still written on every prompt.
