Release 0.3.0 delivers prep as a lifecycle orchestrator: shared lifecycle hooks and Claude Code/Codex integrations, explicit completion contracts, knowledge enrichment and timely retrieval, and versioned human review with a TUI Inbox. Prep guides agents and validates lifecycle transitions; agents execute implementation and checks, while humans own requirements and approval. Hooks provide bounded context, direct agents to existing issues and guides, and report activity without breaking tools on integration errors. The completed cross-project feature and agent behavior suite ship with this release. Under 01M4TST3C4ZSZDKA5WKBA3ND4H, deliver completion-policy and evidence foundations plus the knowledge lifecycle first, then approval/reopening and TUI review, followed by dependency uncertainty, knowledge experiments, local write safety and CLI ergonomics. Reuse existing related issues rather than duplicate their implementations. General installation, CI, remaining desktop and other harness work stays in 0.4.0 unless explicitly moved. Resolve behavior findings only when verified by relevant tests.
