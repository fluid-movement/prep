SwiftPM package in `desktop/` (no Xcode project): library `PrepKit` (Codable models of the CLI's JSON, a `PrepCLI` runner that executes the `prep` binary with `--json --root`, a `prep watch` follower, the tree builder) with `swift test` coverage, and executable `PrepDesktop` (SwiftUI app). The binary is found through `PREP_BIN`, then the usual install locations, then a login shell's `command -v prep`, because apps launched from Finder get a minimal PATH. Reads pass no actor (so they stay out of the activity stream); writes pass `--by human:<user>`. `just desktop` builds and assembles `desktop/build/Prep.app` (Info.plist, ad-hoc signed); `just desktop-test` runs the tests; CI gains a macOS job. Signing with a Developer ID, notarization and the Homebrew cask need the user's Apple Developer account and are split into a follow-up issue. Decision record: [Desktop app](/components/desktop.md) (new knowledge entry).
