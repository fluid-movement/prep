New package `internal/projects`: the registry is machine-local state, not a choice, so it lives in `$XDG_STATE_HOME/prep/projects.json` (default `~/.local/state/prep/projects.json`), not in the user configuration ([Harness setup and user configuration](/components/setup.md) records only choices). `projects.Touch(root, at)` inserts or refreshes a root, skipping the write when it was touched in the last minute; `projects.List()` returns existing projects newest first and rewrites the file when it dropped missing ones. `cli.Main` touches `a.store.Root` after any successful command that opened a project, ignoring errors, next to `recordEvent`. `prep projects [--json]` is a read command that needs no project. CLI tests redirect `XDG_STATE_HOME` in `TestMain`. Document in [CLI](/components/cli.md).
