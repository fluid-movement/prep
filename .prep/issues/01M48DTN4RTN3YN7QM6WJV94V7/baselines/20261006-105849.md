The side panel can switch between the live view (the issue the agent works on, as built in 01M46ARKA817KMB2C92WMNH2QP) and a project view, so the user gets an overview of the project's state without starting the TUI.

- Two tabs at the top of the pane, Live and Project, switch the view: by click, by the keys l and p while the pane has the keyboard, or with /prep:pane live and /prep:pane project (which also open the pane). The live view stays the default; the chosen view is kept for the session.
- The project view shows the overview (bootstrap alert, issue and actionable counts, check result, in progress, attention) and then every unresolved issue as a tree, as prep list --tree lays it out, each row with its state, progress for parents and stale or blocked marks. Resolved issues are not listed.
- The project view is display only: picking an issue does nothing; /prep:focus stays the way to pin one.
- It updates live like the live view.
