New package `internal/eval/run`, using [fixtures](01M4QKVB5EW2N6Y9BDVCFJDC7Q), the [isolated environment](01M4QKVBFKQKCQP6N42BG2K8Z4), the [transcript parser](01M4QKVBMEVANE3EBQM2V2VKR8) and the [case format](01M4QKVBSB5FWC25MM7CB8RBNM).

- **API**: `Run(ctx, Request{Case, Variant, Model, Binary, Auth, Keep bool}) (*Record, error)`; `Record{Case, Variant, Model, Transcript, Stream path, Workspace, Status (completed|timeout|budget|turns|error), Err, Started, Duration}`.
- **Command**: `claude -p <prompt> --output-format stream-json --verbose --model <model> --max-budget-usd <n> --permission-mode bypassPermissions --plugin-dir <variant plugin> --disallowedTools WebFetch,WebSearch --strict-mcp-config --session-id <uuid>`, working directory the primary project, environment from `env.Env`. `bypassPermissions` is acceptable because the working directory is a temp fixture; the isolation issue keeps HOME private, but a run can still touch the real file system outside it, so the case limits and the disallowed tools are the guard. Verify the exact flag set against `claude --help` of the installed version (checked on 2.1.296); a startup check reads `claude --version` and records it in the run.
- **Limits**: timeout via `exec.CommandContext` with a process-group kill; turn limit via `--max-turns` if available, else counted from the stream and killed; budget via `--max-budget-usd`. The reason is read from the `result` event (`stop_reason`, `subtype`) when present.
- **Prompt**: `Expand` from the fixture replaces `{{alias}}`; the expanded prompt is stored in the record.
- **Cleanup**: the workspace is removed unless `Keep`; a failing run always keeps it, path printed.
- **Tests**: a fake `claude` shell script emitting a recorded stream and exercising timeout, nonzero exit, missing auth and budget stop; one real-agent smoke test behind an env var (`PREP_EVAL_LIVE=1`) with haiku and a tiny budget.
