---
title: fold children in list view
kind: code
---

In the TUI list view the user can fold and unfold the children of the selected parent issue with a key. Folded parents show a marker and a child count. A second key folds or unfolds all parents on the selected issue's level.

Why: parents with many children make navigation in the list view difficult (decision by the user: the key acts on the selected issue's children, with a separate key for the whole level).
