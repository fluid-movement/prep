Pi gets the read-only commands Claude Code has as `/prep:status`, `/prep:next` and `/prep:guide [id]`: each runs the read commands the Claude Code command runs and has the model present the result the same way, never running a write command. Without the binary each names the install command, as the Claude Code commands do. Command names fit Pi's command list and are documented next to the Claude Code names.
