The release after 0.1.0: the TUI becomes the place to supervise an agent, and prep's foundations get a thorough audit. Cloud-session installs and the CI check moved to 0.3.0, the Homebrew tap to 0.4.0.

- The TUI: themes, a two-tier navigation (Issues, Agent and Knowledge over each screen's views) that works by keys, mouse and the mouse's back button, an Agent screen that shows what an agent is doing live (its current issue in full, its activity, its usage), a short layout for a strip above or below the agent, a spacing scale, and one meaning per key.
- Agent activity: a local activity stream that prep and harness bridges write, `prep focus` and `prep activity`; the Claude Code plugin slimmed to the skill, the briefing and an activity bridge.
- Configuration per user (`config.yaml` ignored, `config.yaml.dist` shared), prep only staging its writes, and `prep fix` converting projects made with 0.1.0.
- The fixes from the 0.2.0 audit: storage, knowledge drift, git paths, domain edge cases, CLI and integration robustness.

Its children are the work that ships with it.
