Follows the decision in 01M46ARN8RW78DATMQV6P9NVYK; first time prep is distributed. Version stamping already exists: `internal/cli.Version` is set with ldflags by the justfile (`git describe`); GoReleaser sets it to the tag.

- `.goreleaser.yaml`: one build of `./cmd/prep` with `CGO_ENABLED=0`, `-s -w -X github.com/fluid-movement/prep/internal/cli.Version={{.Version}}`, goos darwin/linux/windows, goarch amd64/arm64; archives `prep_<version>_<os>_<arch>.tar.gz` (zip on Windows) holding the binary, README and LICENSE if present; `checksums.txt` (sha256).
- `.github/workflows/release.yml`: on tags `v*`, checkout with full history, setup-go from go.mod, run the tests, then goreleaser-action with `GITHUB_TOKEN`.
- `install.sh` (POSIX sh): detects OS and arch via `uname`, resolves the version (latest via the GitHub releases redirect, or `PREP_VERSION`), downloads archive and checksums with curl or wget, verifies with sha256sum or shasum, extracts, installs with mode 0755 into `PREP_BINDIR` or `~/.local/bin`, and prints a PATH hint. `sh -n` and a dry run against a local fake release in tests.
- `prep update` (`internal/update`, wired in `internal/cli`): fetches the latest release from the GitHub API (`/repos/fluid-movement/prep/releases/latest`), compares semantic versions with `Version`, downloads the archive for `runtime.GOOS/GOARCH` and `checksums.txt`, verifies sha256, extracts the binary and replaces `os.Executable()` atomically (temp file in the same directory, rename; on Windows the old binary is renamed aside first). It refuses with the right command when the binary lives under a Homebrew prefix (`/Cellar/`, `/homebrew/`, `/linuxbrew/`), under GOPATH/bin or GOBIN (go install), or when `Version` is not a release version. `--check` only reports. The API base URL and target path are injectable for tests, which run against an httptest server.
- It is a write command in the sense of the harness (it changes the system), but it touches no `.prep` data.
- Docs: README install section; a new knowledge entry `components/release.md` for the release pipeline, install script and update; [CLI](/components/cli.md) lists `prep update`.
