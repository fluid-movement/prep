The app surfaces the moments that need the person, since the requirement is theirs: issues with open questions to settle and define, defined issues awaiting the ready sign-off, stale issues whose requirement change needs an acknowledgment, and issues completed since the person last looked (with evidence and the documentation they touched). An Inbox screen lists them by kind with one action each; a macOS notification fires when an agent completes an issue or an issue starts needing the person, and the Dock badge counts what is waiting. Seen completions can be marked as reviewed (per machine).
