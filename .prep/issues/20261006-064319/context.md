Touches every layer: [Domain package](/components/domain.md) (`Issue.Tags`, `NewIssueInput.Tags`, `EditInput.Tags`, `Filter.Tags` parsed from `--tag` with commas like `--state`, a validation rule with code I026 for malformed tags), [Markdown store](/components/markdown-store.md) (`issueFM` gains `tags` after `depends_on`; [Storage format](/conventions/storage-format.md) key order), [CLI](/components/cli.md) (`prep new --tag`, `prep edit --tag` replacing the list with `--tag ''` clearing it, tags in `prep list` and `prep show` output and JSON) and the [TUI](/components/tui.md) (tags in list rows and the detail, `--tag` in the filter bar). Tags are not part of the baselined requirement, so changing them never makes an issue stale.
