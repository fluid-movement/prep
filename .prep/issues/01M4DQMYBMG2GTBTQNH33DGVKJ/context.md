Depends on 01M4AWZVXW06G512BPA4Z7G6EC, which adds `prep theme colors [--theme] --json` and the Claude Code plugin option `theme`. Pi styles accept concrete colors: `theme.style(text, { fg: color })` with a `Color` (hex) next to semantic tokens (pi docs, Terminal UI → themes). Load colors at `session_start` and on each `prep watch` line that may concern config; keep them as data and style on render so a theme switch invalidates cleanly. Pi has no plugin userConfig: the option lives where the pane's open preference lives (see the Live view issue's decision).
