The detail listed a parent's children in priority order, cut off after six lines with "… n more · o selects". For a parent with many children, such as a release, it showed a few resolved ones and hid the rest, and offered no way to see them all.

- One heading line: the progress, how many are still open, and a link that opens the issue list focused on this parent (the subtree view `→` already gives), where any number of children scroll, filter and click.
- Below it, up to four unresolved children, in progress first, then by priority; resolved children count only in the progress.
- The heading is a link like any other: a click or link mode follows it, backspace returns.
