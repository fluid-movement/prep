Extends the [TUI](/components/tui.md) issue views (`internal/tui/app.go`); new components go into the [TUI design system](/components/tui-design-system.md) with gallery entries and goldens. Still read-only: no writes from the TUI in this issue.

- Filter bar: `/` opens a Bubbles text input in the list pane; enter applies, esc clears. Input uses `prep list` flags (`--kind code --state open --text csv`, see `ParseFilter` in `internal/domain/query.go`); bare words become `--text`. The filter narrows the current tab: the tab's query and the filter's query run separately and are intersected, because repeated flags in one `ParseFilter` call OR together. The active filter shows in the list pane title; a parse error shows under the input and keeps the previous filter.
- Stale diff: for stale issues (`Tree.Stale`) the detail starts with a line diff of the newest baseline's `Requirement` against the current `Issue.Body`, and the kind change when the kind differs. A small LCS line diff in `internal/tui/ui` (`DiffLines`) feeds a `ui.Diff` component that colors added and removed lines from tokens; it is prepended to the rendered markdown in the viewport.
- Check screen: `c` replaces the body with all diagnostics of `domain.Validate` grouped by severity, each with code, location (issue or entry and file), message, class and fix text. Knowledge drift needs git (about 170 ms against 10 ms for a plain load), so `Options` gets a separate `Check` loader (the CLI's `a.load(true)` plus `Validate`) that runs when the screen opens and on reloads while it is open; the issue views keep the fast loader. The header shows error and warning counts from the last check run.
- Settings screen: `s` shows the project configuration read-only: schema version, commit mode, saved views with their flags in order, and the project Definition of Done, rendered as markdown.
- esc or the same key leaves either screen; tabs keep their state.
- Tests in `internal/tui/app_test.go`: filter intersection and parse errors, the stale diff on a fixture issue whose requirement changed after define, check screen content with a broken fixture file, settings content; gallery entries for the diff and diagnostics rows.
