Follow-up of the two-tier navigation (01M4EA4RB500QF2449Y3914VMQ), which ships the Knowledge screen without tier-two views but on the same view mechanism as the issue lists, so views can be added without new navigation code.

Find out what views the Knowledge screen should offer, given the OKF bundle's shape (entry types, directories, statuses, scopes, attention from the check):

- tabs by entry type (components, features, decisions, conventions) or by bundle directory;
- configurable knowledge lists in config.yaml, like issue views, using the knowledge filter (`--type --status --scope`, words);
- an attention view replacing `a`;
- what other OKF tools do.

Findings recommend one option with its config format, if any.
