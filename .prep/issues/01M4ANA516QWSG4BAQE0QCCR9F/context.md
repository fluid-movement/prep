`domain.Filter` (`internal/domain/query.go`) gains excluded lists per list flag (states, kinds, tags, priorities, under); `ParseFilter` splits values on a leading `!`; `Tree.Query` applies them. The TUI intersects tab and filter queries, so nothing changes there except `parseFilterText` (unchanged parsing) and the picker in `internal/tui/complete.go` (a typed `!` keeps the prefix and completes the value). `prep flags` text header (`internal/cli/read.go`) and the `list` usage line mention `!`.
