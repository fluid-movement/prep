A value of a list query flag can be negated with a leading `!`: `--state !open` lists every issue that is not open. This works for `--state`, `--kind`, `--tag`, `--priority` and `--under`, everywhere queries are read: `prep list`, saved views, the TUI filter bar.

- Within one flag, negated values exclude and plain values include: `--state !open,!done` is neither open nor done; `--state ready,in_progress,!dropped` is ready or in progress. An issue matches a flag when it matches one of the plain values (or there are none) and none of the negated ones.
- `--tag !cli` matches issues without the tag; `--under !<id>` excludes an issue's descendants.
- Negated values are validated like plain ones (`--state !nope` is an error).
- Shells expand an unquoted `!`, so the CLI help and README show `--state '!open'`; views and the filter bar take it unquoted.
- `prep flags` mentions negation, and the filter bar picker offers values after `!` as well.
