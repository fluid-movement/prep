## D1: Preview on the real issue screen with a footer theme bar
date: 2026-10-07

The theme preview runs on the issue screen with the project's data; the theme list is a bar in the footer, not a dialog. enter keeps, esc restores, both return to settings.

Rationale: a theme is judged on what the user looks at all day; dialogs dim the screen behind them, which would defeat the preview; one line in the footer leaves the whole screen visible. Saving only on enter makes trying themes free.

Alternatives: side-by-side compact samples (small, not the real screen); previewing on the settings screen (shows little color); saving on every move (today's behavior, a theme change for each try).
