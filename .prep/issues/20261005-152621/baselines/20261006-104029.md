A side panel in Claude Code shows what the agent is working on, so the user keeps context and can make decisions while the agent defines, enriches and implements an issue. It is display only: the conversation stays the place to act.

- The panel follows the issue the agent is working on, inferred from what the agent does: any prep write naming an issue, prep guide for an issue, prep new (the issue it created) and edits to files under .prep/issues/<id>/ make that issue current; looking around (prep show, list, next) does not. Each session follows its own agent. Before the session has touched an issue, the panel shows an issue claimed in this repository; with none, the project at a glance (bootstrap alert, in progress, actionable, attention, top-level parents with progress).
- For the current issue it shows where it stands (title, id, kind, tags, state and step, stale or blocked warnings, what blocks the next transition and the next command), the requirement, open questions, the acceptance checklist with progress and the Definition of Done, the decisions recorded, and its surroundings: parent and progress, dependencies and what it blocks, children, knowledge entries in play, and the last history lines.
- It updates live whenever anything under .prep changes, through a new prep watch command that streams a line per change and can serve other harness integrations too.
- /prep:focus <id> pins the panel to an issue when inference guesses wrong; /prep:focus without an id returns to following the agent. /prep:pane opens or closes the panel.
- A pane option decides whether the panel opens at session start in a prep project: remember (default, like /diff: as the user left it), open or closed. It is set in Claude Code's plugin settings, per user or per project.
- The panel is part of the prep plugin, so prep setup installs it with the rest.
