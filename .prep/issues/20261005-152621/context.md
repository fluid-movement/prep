- `prep watch` (`internal/cli/watch.go`): the TUI's fsnotify watcher (`internal/tui/watch.go`) moves to `internal/watch` so the CLI and the TUI share it; the command prints one line per debounced change (`{"event":"changed"}` with `--json`) until killed. A read command.
- `prep show --json` gains `history` (the work log text), which the panel's surroundings need.
- The mod is the prep plugin's hooks module ([Claude Code integration](/components/claude-code.md)): `plugins/claude-code/hooks/hooks.json` names `./register.tsx` under `modules` next to the existing SessionStart command hook; `types/index.d.ts` declares its `$.state`; `plugin.json` declares the `pane` `userConfig` option (string with options remember, open, closed). Developed with hot reload in the session's dev-mods folder, then moved into the plugin.
- Module: `tool.call` hooks on Bash (parse `prep <subcommand> <id>` from the command, after the call so failed commands do not move focus; `prep new` takes the id from the output) and on Edit/Write (paths under `.prep/issues/<id>/`). Focus, pin and the last snapshot live in `$.state`; `$.store` remembers per project whether the pane was open, for `remember`. Data comes from `prep show <id> --json`, `prep guide <id> --json` and `prep prime --json` through `$.process.run`; `prep watch` runs through `$.process.spawn` for the session and triggers a refresh per line. Outside a prep project (prime --hook prints nothing) the mod stays idle.
- Drawing: a `ui.render` hook on the pane with the engine's Box and Text, colors matching the TUI design system's tokens, sections clipped to the pane's rows.
- Tests: `claude plugin test` for the inference and rendering with the process calls mocked; `claude plugin validate`; Go tests for prep watch and the history field; a live try in this session.
