Agreed with the user on 2026-10-18: prep never runs other agents, but helps when an agent wants to delegate. prep guide offers the handoff prompts for implementing and reviewing; implementer and checker are passes, so a solo session implements, checks separately and completes, while an orchestrated one stops at ready for check; once the work log says ready for check, prep guide gives a checker brief a review subagent can follow from the issue alone. Delegation stays the orchestrating agent's judgment.
