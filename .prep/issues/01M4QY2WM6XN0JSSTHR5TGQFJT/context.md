What the suite measures and how (summary of [Agent behavior tests](/components/eval.md)): a case is a prompt in a fake project; the runner starts Claude Code headless in an isolated environment with the plugin under test (`eval/variants/`), records the stream, and checks tool use (`prep eval` tools assertions) and the project's state afterwards (outcome assertions) and, for text quality, a rubric graded by a judge model. `prep eval run --case <name> --models haiku --n 5` reruns one case; `--variants none,skill-only,hook-only,current` swaps the plugin.

Where it stands on haiku (the cheap model; sonnet is better on some): 3/3 on routine work (define, enrich, claim and log, complete, batches of chores, cross-project reads and dependencies, injection and evidence traps, subagent audits); 0/3 on filing a bug without duplicating an existing issue, on an ambiguous reference, and on tracking a fix the user asked for in plain words. Total cost of the whole suite on haiku: about $0.70 at API prices.

How to reproduce and verify (agent behavior suite, see [Agent behavior tests](/components/eval.md) and [its cases](/components/eval-cases.md)): `just build`, then `just eval-login` once (stores a Claude token), then the commands named below. Results are written to `eval/results/<run-id>/` (git-ignored, per machine); `prep eval report <run> --failures`, `prep eval errors <run>`, and the `transcript.json` of each run show what the agent did.
