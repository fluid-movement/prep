A bar at the top of every screen names the screens (Issues, Agent, Knowledge), marks the current one and switches on a click or the screen's key. The issue lists move below it as tier two, so the screen bar is never mistaken for a list tab. Clicking a list from another screen goes to Issues on that list, and the bar is always one click back.

The Agent entry shows whether the agent is active (a live dot and how long ago), so the bar doubles as the signal that something is happening while another screen is shown.

Keys, and where Check and Settings go, follow the parent's decisions.
