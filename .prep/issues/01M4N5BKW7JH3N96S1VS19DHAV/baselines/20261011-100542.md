A global `--project <name|id|remote|path>` (and `PREP_PROJECT`) runs any prep command against another registered project, the way `--root` does for a directory: reads (`show`, `list`, `guide`, `knowledge find|show`, …) and writes (`new`, `edit`, `log`, `decide`, …).

- Resolution: an exact name, then an ID (any unique suffix), then a remote, then a path. Several clones of one project (one ID): the most recently used one wins. A name shared by several IDs lists the candidates and fails with a usage error. An unknown project fails and lists the registered ones.
- Writes stage in the other project's repository and never commit, as they do at home; the output says which project was written, so an agent does not mistake it for the current one.
- Activity goes to the other project's activity stream with the actor, and the current project's stream notes the cross-project command, so the TUI of either project shows it.
- `--project` and `--root` together are a usage error.
- The prep skill and `prep prime` teach it: how to find another project (`prep projects`), and that `--project` is how to read or file work there.
