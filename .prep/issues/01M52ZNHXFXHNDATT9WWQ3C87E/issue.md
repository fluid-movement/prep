Release 0.3.0 delivers the decisions of the rethink (01M4ZCK8C17RDGBVCTMQPGMEK7): prep makes issues clear and records what was decided and learned, with far less machinery. Removals come first, then the knowledge model, guidance and a final prune sweep that deletes everything prep does not use. The earlier 0.3.0 scope was never tagged and is superseded. Each child is small and done only when GitHub CI on main is green; changes to gates, hooks or guidance come with an eval case that fails without them.
