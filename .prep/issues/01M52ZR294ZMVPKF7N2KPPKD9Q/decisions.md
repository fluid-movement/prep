## D1: No knowledge bootstrap: knowledge starts empty and grows from records
date: 2026-10-17
outcome: true

User decision, 2026-10-17. With knowledge as decision and finding records, prep has no bootstrap: prep init creates no knowledge issues, and prep knowledge bootstrap and the G_BOOTSTRAP gate go away with the knowledge model (01M52ZRB3VY0MSZ0HZWJ2SEC24). Records accumulate through prep decide and prep finding as issues are worked. A project that wants its existing decisions captured (from README, docs or git history) files an ordinary issue for it; no command or guidance supports that path. A guided mining pass was rejected as machinery that fails the overhead test: the pilot showed bootstrapped-style knowledge cost about 60% more input tokens with no measured benefit.
