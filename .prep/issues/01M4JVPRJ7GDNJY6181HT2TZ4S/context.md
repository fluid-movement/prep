`ProjectSwitcher` in the toolbar (`ContentView.swift`) lists `prep projects` merged with the app's own recent projects (UserDefaults, for binaries without the registry); choosing one reopens the window's `ProjectModel` (`open(path:)`: new `PrepCLI` root, new watcher). ⌘N opens another window with its own project. The launch directory (argument or `open -a`) selects the project; any directory inside a project resolves to its root. See [Desktop app](/components/desktop.md).
