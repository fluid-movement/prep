`prep tui` gets an Agent screen that shows, live, what the followed agent is doing, meant to run in a split next to the agent all day and to be fun to watch.

- **Now**: the followed actor and its current issue as a compact card: title, kind, state, step, acceptance progress, next transition with unmet gates; it opens the issue's detail on request.
- **Feed**: the activity stream newest first, a glyph per area (issue, knowledge, code, tests, prep), relative time, verb and target, grouped under the issue it belonged to so moving between issues reads like chapters. The wheel scrolls it.
- **Usage**, when a harness reports tokens: context fill, tokens this session (input, cache read and write, output), what was read back by area, the largest knowledge reads; for the current issue, commands run, criteria checked and knowledge read.
- **Fun**: a brief highlight when an event lands, a line celebrating a completed issue (how many commands it took), an idle note after a quiet spell; nothing animates while nothing happens.
- Several actors: follows the most recent, a key cycles through them, the header names whose activity shows.
- `prep tui --agent` opens on it. Activity changes refresh only the Agent view's data, not the issue tree.
- Keys follow the TUI's letter melodies; it uses the design system's tokens and components, appears in the gallery where it adds components, and works in every theme and at narrow widths.
