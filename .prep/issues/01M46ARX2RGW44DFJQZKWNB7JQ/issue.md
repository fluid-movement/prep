Third-party storage adapters (Postgres, hosted, a search engine for knowledge) speak JSON-RPC over stdio, like LSP and MCP, so the core stays a closed, tested binary. Define the protocol for the issue and knowledge store ports and run the contract corpus against an external adapter.
