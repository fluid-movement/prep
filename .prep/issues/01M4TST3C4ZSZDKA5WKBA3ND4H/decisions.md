## D1: Contract interface, not implementation orchestration
date: 2026-10-13

User decision from interview: prep defines and validates the contract. Agents execute checks and implementation; commit timing is a user choice. This supersedes the earlier interview suggestion that prep itself execute trusted commands.

## D2: TUI-first human workflow and delivery order
date: 2026-10-13

Deliver completion/review contract and TUI Inbox/review first, then dependency uncertainty and knowledge experiments. Migrate useful desktop behavior and tests, then delete the desktop app. Human feedback stays in the agent conversation; TUI review offers approval and issue-ID copying, not rejection or changes-requested verdicts. Eval prioritizes contract compliance first; implementation quality follows. Small-change shortcuts, MCP, dedicated adapters, and distributed coordination are deferred.
