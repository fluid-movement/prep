Prep orchestrates a consistent issue lifecycle: capture and define requirements, enrich implementation context with relevant knowledge, sign off readiness, guide implementation, validate verification and knowledge impact, record completion, and support versioned human review and reopening. Agents execute implementation and project checks; prep guides the next step, enforces transition contracts and records evidence. Humans own requirements and approvals; commit timing remains a user choice. Require an explicit project verification and documentation policy before readiness. Before completion require affected knowledge to be updated or explicitly reviewed as unchanged, or a justified no-impact assessment; listing an entry alone is not review evidence. Offer relevant knowledge at the lifecycle steps where an agent needs it using bounded CLI guidance and targeted retrieval. Deliver completion-policy/evidence foundations and the knowledge lifecycle first, then human approval/reopening and TUI Inbox/review. Follow with explicit cross-project uncertainty, comparative knowledge experiments, local write safety and CLI ergonomics. Keep OK Format, CLI-first integration and shared domain gates. Defer distributed scheduling, MCP and dedicated external adapters. Reuse existing related issues for freshness, hooks, bounded output, evaluation and desktop migration.
