`complete` in `internal/tui/complete.go`: when the word being typed is empty and the token before it finishes a flag (a list or text flag's value, or a boolean flag), it offers the flags not used yet in `QueryFlags` order, repeatable ones (`under`, `text`) last even when used. After a bare word, after a list flag still waiting for its value, and on empty input it offers nothing, so enter keeps applying. A picked value inserts no trailing space, so the picker only reopens when the user types the space. See [TUI filter bar](/components/tui-filter.md).
