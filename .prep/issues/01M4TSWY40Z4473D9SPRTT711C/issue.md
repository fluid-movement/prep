Keep OK Format as the current storage contract while experimenting with content and retrieval. Default knowledge should preserve decisions, constraints, and navigation hints; agents inspect code for implementation facts. Use a small project briefing and targeted retrieval. Review existing comprehensive entries incrementally as touched, pruning duplication while preserving useful rationale. Documentation is part of implementation: update affected entries before completion or record an explicit reason why no update is needed, rather than defer documentation to a follow-up. Report potentially affected entries and last review revision without claiming semantic correctness. Compare code-only, current knowledge, and lean knowledge on identical repository snapshots/tasks, including deliberately stale entries. Primary evaluation priority remains contract compliance; collect correctness, missed constraints, and time/token/maintenance overhead as exploratory outcome measures.
