The TUI's tabs are the saved views in `.prep/config.yaml`. `prep init` writes six of them: Attention (`--stale`), Actionable (`--actionable`), In progress, To enrich, To define and All. The user spends most of the time in all unresolved work, which these split over three state tabs while the state glyphs on each row already tell the states apart; ready issues have no tab of their own; stale and actionable issues are visible in a combined list through the row notes, and `prep next` serves the actionable list to agents. This repository already uses the two views below.

`prep init` writes two views instead:

- Unresolved: `--state open,defined,ready,in_progress`
- All: `""` (every issue, done and dropped included)

The name is Unresolved, not Open, because open is also the state of an issue that is not yet defined. Existing projects keep their config; anyone who wants other views edits them in the settings screen or the file. The query language does not change.
