## Requirement

Make the activity stream's request events attributable and their coverage observable, so `prep activity report` can state what prep costs without transcripts.

- Claude Code module (`plugins/claude-code/hooks/register.ts`, `turn.step` handler near lines 78-105): add `e.agentId` (and agent type if available) to each request event, and the request/message ID if the turn event exposes one. Add the field to `activity.Event` and to the `prep activity add` input parsing, keeping old events readable.
- Delivery: do not lose batches silently. When `send` fails or the bridge disables itself, record a gap marker event (or count) that the report can read; do not retry-loop.
- Codex: install a PostModelRequest hook (and map agent_id, turn_id, status, token_usage) into the shared hook code in `internal/cli/hook*.go`, writing request events; failed or cancelled attempts without usage are counted as gaps, not zero.
- Report: group request tokens by agent, show main vs subagent, and say partial/unknown when a gap marker or missing usage exists; never add transcript totals. Treat `turn.complete` context/cost summaries as summaries, not requests; do not attribute cumulative session cost deltas to agents.
- Not in scope: parsing transcripts or adding a SubagentStop cost hook (decided against, see finding 01M75HAAS1DYCVPA0YNN8CF43K and 01M75GQ1HEVNX6MZ6M9SYZE4HQ).

Context: the stream matched transcripts 110 of 110 requests in the measured session; the gaps are attribution and observability.
