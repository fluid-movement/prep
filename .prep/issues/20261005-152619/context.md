Shows the knowledge base read-only ([TUI](/components/tui.md), [TUI editing and keys](/components/tui-editing.md), [OKF store](/components/okf-store.md), [Domain](/components/domain.md)).

- Entry bodies: `domain.Entry` gains `Body string` (json `-`), filled by the OKF adapter (`internal/okf/okf.go` already splits frontmatter and body when it parses links). Nothing else reads it.
- Backlinks: `domain.Tree.EntryIssues(path)` returns issues whose `Resolution.Documentation.Entries` name the entry, newest first; `Tree.IssueEntries(id)` returns an issue's `ContextLinks` plus, when resolved, its documented entries, deduplicated, existing entries only.
- Filter: `domain.KnowledgeFilter` with `ParseKnowledgeFilter(args)` (`--type`, `--status`, `--scope` glob via `ScopeMatch`, bare words matching the title) and `Tree.QueryKnowledge(f)`, ordered by path; in `domain` so a CLI listing can share it later.
- Screen: a `screenKnowledge` next to check and settings, opened with `b` (bundle; `k` is cursor movement), esc or `b` returns. List pane on the left (`ui.ListRow`-like rows: type, status, title, an attention mark), the rendered entry on the right in a viewport (`ui.Markdown` of the body, a meta line with type, status, scope and confirmed commit, then "Changed by" with the backlinked issues as links). `f` filters as on the issue screen; `a` toggles attention-only. Keys and `?` come from a `knowledgeBindings` table (see the keymap in [TUI editing and keys](/components/tui-editing.md)).
- Attention: the knowledge screen runs `Options.Check` when it opens (as the check screen does) and keeps the K-coded diagnostics by entry file (`K003` broken link, `K004` size, `K005` drift, `K006` unknown commit); until the check returns, marks show as pending. Warnings only inform; nothing is fixed from the TUI.
- Issue detail: the relations block gains a "Knowledge" line group (`relation` label `knowledge`) for `IssueEntries`; `o` lists them with the other links and jumping to one opens the knowledge screen with the entry selected; backspace returns to the issue.
- Tests: domain tests for backlinks, `IssueEntries` and the filter; TUI tests and goldens for the screen at both sizes, the filter, attention marks after a fake check, and jumping from an issue to an entry and back.
