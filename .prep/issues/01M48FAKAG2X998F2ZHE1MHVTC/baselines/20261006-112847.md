The first public release of prep: a user can install it with one command, their agent harness knows prep from the next session on, and the TUI is in a good place for the human side of the work. The children of this issue are the work that must be done before the release; everything else waits for a later version.

- The release workflow publishes archives and checksums for macOS and Linux (amd64, arm64) for the tag v0.1.0, and the plugin and marketplace manifests carry 0.1.0.
- curl -fsSL https://raw.githubusercontent.com/fluid-movement/prep/main/install.sh | sh installs the binary and, with a terminal attached, runs prep setup; on a machine with Claude Code, a new session in a prep project then shows the prime briefing from the plugin, which is pinned to the tag.
- The README explains what prep is and how to install, set up and update it.
- The TUI covers the human side well: browsing, editing, the knowledge view, theming and mouse support, as its children describe.
