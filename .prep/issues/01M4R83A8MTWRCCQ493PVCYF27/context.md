Where the row is drawn: `ui.ListRow` in `internal/tui/ui/components.go` builds `marker + ID + " " + StateBadge + KindTag + tree + note + priority + title + tags` for result rows, and a plain-text equivalent for dimmed context rows (`fmt.Sprintf("%s %-*s%-*s", r.ID, BadgeWidth, glyph+" "+label, KindWidth, kind)`); both widths are fixed (`BadgeWidth` for the state glyph and label, `KindWidth` for the kind). `Model.issueRow` in `internal/tui/app.go` fills `ui.Row` and `app.go` calls `ui.ListRow(m.th, m.row(...), selected, inner)` with the pane's inner width, so `ListRow` already knows the width it has; hiding columns can be decided there (or by a `Row`/options value the caller sets from the width).
