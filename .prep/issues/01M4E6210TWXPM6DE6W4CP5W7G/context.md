- Splits are decided in three places: `render` in `internal/tui/app.go` (issues, `ui.Split(m.w, listRatio, minListW, minDetailW)`, one pane is the focused one), `knowledgePane` (`knowledge.go`, list or entry by `know.onEntry`) and `agentPane` (`agent.go`, the stacked Now-over-feed layout). A `Model.split` helper returns the whole width and zero when one pane is chosen, so all three follow.
- Key `z` (zoom, as in tmux; free on every screen) toggles from any screen, flashing the new mode; non-essential binding under Screens.
- Persistence like mouse capture ([TUI mouse](/components/tui-mouse.md)): `userconfig.TUI.Layout` (`layout: single`, unset means split), `Options.Single` and `Options.SaveLayout` from `internal/cli/tui.go`; a save failure flashes the error and keeps the toggle for the session.
- Tests: goldens of the issue and Agent screens at 110×28 in one-pane mode, a key test (toggle, save called), userconfig round trip. Knowledge: TUI, TUI Agent screen, setup (user configuration).
